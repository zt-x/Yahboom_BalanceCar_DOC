## K210(K210)

<div class="notice">
    <p>K210模块是一个优化过图像处理能力的边缘计算设备，通过UART2和小车通讯</p>
</div>



### 全局变量

<table border="1">
<tr><th>全局变量</th><th>类型</th><th>注释</th></tr>
<tr><td>buf_msg</td><td>char[20]</td><td>K210 接收消息缓冲区</td></tr>
<tr><td>g_new_flag</td><td>uint8_t</td><td>接收标志，用于指示是否正在接收新消息</td></tr>
<tr><td>g_index</td><td>uint8_t</td><td>消息索引，用于存储接收的字符</td></tr>
</table>


### 宏定义

<table border="1">
<tr><th>宏定义</th><th>值</th><th>注释</th></tr>
<tr><td>BUFFER_SIZE</td><td>40</td><td>K210 接收缓冲区大小</td></tr>
</table>


### 方法

#### USART2_init(u32 baudrate)
初始化 USART2（用于 K210 通信）
<table border="1">
<tr><th>参数</th><th>类型</th><th>注释</th></tr>
<tr><td>baudrate</td><td>u32</td><td>波特率</td></tr>
</table>
<table border="1">
<tr><th>返回值</th><th>类型</th></tr>
<tr><td>无</td><td>void</td></tr>
</table>

#### K210_Deal_Recv(uint8_t recv_msg)
解析 K210 模块发来的消息
<table border="1">
<tr><th>参数</th><th>类型</th><th>注释</th></tr>
<tr><td>recv_msg</td><td>uint8_t</td><td>接收到的字符</td></tr>
</table>
<table border="1">
<tr><th>返回值</th><th>类型</th></tr>
<tr><td>返回接收的完整字符串</td><td>char*</td></tr>
<tr><td colspan="2">默认情况下以'$'字符作为数据包头, 以'#'作为数据包尾</td></tr>
</table>

#### K210_Send_Msg(const char *data_str)
向 K210 模块发送字符串消息
<table border="1">
<tr><th>参数</th><th>类型</th><th>注释</th></tr>
<tr><td>data_str</td><td>const char*</td><td>待发送的字符串</td></tr>
</table>
<table border="1">
<tr><th>返回值</th><th>类型</th></tr>
<tr><td>无</td><td>void</td></tr>
</table>

#### USART2_Send_U8(uint8_t ch)
发送一个字符到 K210 模块
<table border="1">
<tr><th>参数</th><th>类型</th><th>注释</th></tr>
<tr><td>ch</td><td>uint8_t</td><td>要发送的字符</td></tr>
</table>
<table border="1">
<tr><th>返回值</th><th>类型</th></tr>
<tr><td>无</td><td>void</td></tr>
</table>

#### USART2_Send_ArrayU8(uint8_t *BufferPtr, uint16_t Length)
发送一个字节数组到 K210 模块
<table border="1">
<tr><th>参数</th><th>类型</th><th>注释</th></tr>
<tr><td>BufferPtr</td><td>uint8_t*</td><td>待发送的数据指针</td></tr>
<tr><td>Length</td><td>uint16_t</td><td>数据长度</td></tr>
</table>
<table border="1">
<tr><th>返回值</th><th>类型</th></tr>
<tr><td>无</td><td>void</td></tr>
</table>

#### USART2_IRQHandler(void)
USART2 中断服务函数，处理接收到的数据
<table border="1">
<tr><th>返回值</th><th>类型</th></tr>
<tr><td>无</td><td>void</td></tr>
</table>

<span class="keyword">void </span><span class="function">USART2_IRQHandler</span>(<span class="keyword">void</span>) {
    uint8_t Rx2_Temp;
    <span class="keyword">if</span> (USART_GetITStatus(USART2, USART_IT_RXNE) != RESET) {
        USART_ClearITPendingBit(USART2, USART_IT_RXNE);
        Rx2_Temp = USART_ReceiveData(USART2);
        <span class="keyword">char*</span> res;
        res = K210_Deal_Recv(Rx2_Temp);
        <span class="keyword">if</span>(res != <span class="keyword">NULL</span>) {
            printf(<span class="string">"recv: %s\n" </span>, res);
        }
    }
}
